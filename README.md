## Descripción del proyecto

Este proyecto corresponde a una práctica de Programación Orientada a Objetos desarrollada en Java. El proyecto representa un sistema relacionado con un aeropuerto y utiliza diferentes clases para representar personas, empleados, pasajeros, pilotos, vuelos, aviones, boletos, equipaje y aerolíneas.

Se aplican conceptos de Programación Orientada a Objetos como encapsulamiento, abstracción, herencia, constructores, métodos `set`, `get` y `toString()`.

El proyecto también cuenta con una interfaz gráfica desarrollada mediante `JFrame` y `JTabbedPane`.

## Clases desarrolladas

El proyecto contiene las siguientes clases:

* Persona
* Piloto
* Pasajero
* Equipaje
* Empleado
* Boleto
* Avion
* Aerolinea
* Sobrecargo
* Vuelo

## Funciones

Cada clase cuenta con una interfaz para realizar diferentes operaciones:

* Crear
* Buscar
* Mostrar
* Actualizar
* Borrar
* Destruir

También se incluyen validaciones para controlar los datos introducidos por el usuario.

## Requisitos

Para ejecutar el proyecto se necesita:

* Java JDK
* NetBeans IDE

## Instrucciones para ejecutar

1. Descargar o clonar este repositorio.
2. Abrir NetBeans.
3. Seleccionar **File → Open Project**.
4. Seleccionar la carpeta del proyecto.
5. Abrir el proyecto.
6. Ejecutar la clase principal.
7. Utilizar las pestañas de la interfaz gráfica para probar las diferentes clases y operaciones.

## Interfaz gráfica

La aplicación cuenta con una ventana principal utilizando `JFrame` y un `JTabbedPane`. Cada pestaña corresponde a una de las clases principales del proyecto.
